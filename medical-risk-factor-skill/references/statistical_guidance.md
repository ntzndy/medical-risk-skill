# 统计决策与结果核查

阶段3前读取，阶段4–5沿用。以下约束只适用于已确认范围，不扩展到未选字段。

## 阶段1–2的前置条件
- 先读表头，向用户提问研究人群、希望分析的疾病/事件及结局定义/时间窗，等待真实反馈。不得从文件名或列名自动代定目标；目标未确认不展示变量选择任务。
- 阶段2列出所有原始字段，锁定已确认结局，由用户决定解释变量及授权辅助字段；未确认不做质量统计。改变目标需回到阶段1，改变选择需重核阶段3及后续。

## 阶段3：核查与数据处理
- 先按[异常审核](quality_review.md)展示具体证据并征求用户意见。缺失分为0%至30%（不含端点）、30%至50%（含端点）、大于50%三组，无缺失另列。低组按用户要求默认拟采用多重插补，其余待定；每组逐变量仅显示“变量名 / 缺失比例 / xx%”，列表后提供一个意见框。详细数量与结局分布保留在核查文件，按需核对。默认是工作流偏好，不是适用性结论或执行授权。文字意见由代理整理成逐变量方案并确认后才可执行已实现方法。特殊编码不单列疑似缺失码、不自动设空；混杂列展示实际形式和频数，极端值展示阈值与实际范围。
- 沿用阶段1已确认的人群与结局，补问当前处理所需的候选暴露时序、纳排条件、变量含义及结构。研究设计和独立观测适用性须在阶段4正式确认；明确不适用时提前停止，不擅自套用普通 Logistic。
- 区分真正缺失、结构性不适用、未测量、检测上下限、录入错误、特殊编码及真实临床异常。核查脚本仅提供线索；单位/医学范围、分位数、按结局缺失分布等须按需要补充，未做不能声称已做。
- 保留、核对来源、设缺失、重编码/单位修正及排除均记录依据；涉及改值/删除须具体规则。授权处理另存分析集，列出处理前后人数、原因、结局组影响与版本。待溯源问题不能写成已解决。
- 更新剔除/派生/辅助变量时重核范围；禁止对未选字段做全表 dropna 或去重。
- 阶段3内部按“核查 → 建议 → 用户确认 → 执行 → 复核”推进，不把验证审核 JSON 当作修复完成。新增/加重或修改后仍存的线索须再获反馈，未复核不进入阶段4。

### 缺失策略
- 逐变量计算缺失数/比例和按结局组分布，保存在核查文件；默认页面与对话仅展示名称和比例。评估方法时按需讨论与结局/暴露关系、有效样本和选择偏倚。缺失率仅为预警，没有万能的 5%/20% 阈值；检验不能单独判定 MCAR/MAR/MNAR。
- 提供逐模型完整案例、排除解释变量、多重插补、来源补录、结构性不适用/检测界限专项处理等有依据选项，默认精简展示实际缺失比例，必要时再核对按结局分布、预计有效 N与局限，由用户决定。当前执行器仅实现完整案例及授权排除变量；选择MI/补录/专项方案时记录并暂停，不自动换成完整案例。结局缺失和结构性缺失不得随意插补。
- 正式推断不默认使用均值/中位数/众数单次填补。合理 MAR 下可设计 MI：含结局、分析及已授权辅助变量，按类型设模型，考虑非线性/交互与层次，按 Rubin 法则合并。
- 本包只实现 `complete_case`，不实现 MI，也不能将单次填补冒充 MI。新增辅助变量先获授权、再核查。

### 类型与编码
- 二分类核对真实含义、阳性值和参考组，不按字母顺序猜测。
- 无序多分类创建 k-1 指示变量，列水平样本与事件数；稀疏类别合并需临床理由和确认。有序变量原则上先分类，有依据时再做趋势检验，不默认等距。
- 连续变量优先保留连续信息，确认单位、比较增量和合理范围；线性 logit 假设须复核，未自动检查时列为局限。需要非线性变换/RCS时说明当前脚本未实现，不声称已做。不能按最小 P 值找最佳截点。
- 偏态描述可用中位数(IQR)，不意味着回归自变量必须正态。
- 同源/派生变量（年龄与分层、肌酐与 eGFR）核对共线性、数学耦合和结局泄漏；结局定义组成项不得未经说明当危险因素。
- 锁定变量字典：原字段、含义、类别、角色、类型、单位、参考组、映射、选择、理由、缺失处理和版本。全部原始字段与选择清单须一一覆盖。

## 阶段4：Logistic 方案确认
- 依据临床知识、时序、DAG 和预定混杂集调整，不以单因素 P<0.05/0.1 为唯一入模标准；中介、碰撞变量及后果变量不得不加区分地纳入。
- 仅提供独立观测、二分类结局的单因素及多因素 Logistic，默认两者均执行，也可明确确认仅其中之一。报告粗 OR、aOR、95% CI、P、参照组及每单位/特定增量。OR 非 RR；常见结局尤其不能当风险倍数。
- 明确全部单因素变量和多因素调整集，后者只能从已核查并保留的变量中选；多因素至少两个解释变量。调整集变化后重新展示对应完整案例 N/事件数并确认，不按单因素显著性自动筛选。
- 连续/生存结局、匹配、聚类、重复测量或需要 RR/PR 等场景不在本版范围；停下说明，不自动增加模型或改变研究目标。
- 核对事件/非事件数、参数自由度（包括分类水平、样条基函数）、稀疏单元、分离、共线性和过拟合。10 EPV 不是普适保证。分离时考虑适用的 Firth 等实现，不直接解读极端估计。
- 提交执行确认单：设计与独立观测、结局阳性值/窗口、单因素变量、多因素调整集、编码/单位/参照、完整案例策略及预计 N/事件数。用户确认前不拟合。亚组、交互、Firth、非线性与敏感性分析未实现，不混入主分析或声称已做。

## 阶段5：执行、解释与交付
- 按设计生成 Table 1、单因素及多因素，列出实际分母、缺失、每模型有效 N 和事件数；单/多因素样本不能默认相同。
- 审查分布、分离、共线性、收敛、异常影响点与稳健性；Hosmer–Lemeshow 不是唯一质量标准。重点是效应估计和偏倚控制，未实现的诊断如实列局限。
- 结果以效应量、CI、方向及临床意义为主。观察性关联不证明因果，横断面患病优势不可写成新发风险；解释须对应编码方向和尺度。
- 生成结果后继续阅读 `audit.json`、单/多因素结果及报告，围绕阶段1问题给出初步回答，比较粗与调整估计及各自样本差异。自动草稿只是本阶段中间产物，不能以“文件已生成”结束；诊断不充分或模型失败时明确无法可靠判断，不列作已证实危险因素。
- 只在相应阶段生成产物：字段盘点/选择；选定范围质量报告；最终 `analysis_plan.md`、`variable_dictionary.csv`、`missingness.csv`、`table1.csv`、`univariable.csv`、`multivariable.csv`、`forest_plot.png`、`analysis_report.md`、`audit.json`。不适用/失败标明原因，不补造文件或数值。
- 使用 `assets/report_template.md` 写设计、样本流转、处理、方法、结果、诊断与局限，清楚说明粗/调整估计及精度，覆盖 STROBE 报告要点。通用术语仅解释一次：n/N、事件、n(%)、均值±SD、中位数(IQR)、β、SE、OR/aOR/RR/HR、CI、P、reference、VIF、NA；具体结果解释方向及 CI 跨无效值的含义。
